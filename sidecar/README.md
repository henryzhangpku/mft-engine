# Text-signal sidecar

Scores news or social posts into `TextSignal` events (JSONL) that the Rust
engine reads alongside market data. The engine may only use them to reduce or
veto exposure; see `src/text.rs`.

The posts in `posts_sample.jsonl` are **synthetic**, generated by
`make_posts.py` from fixed templates and a fixed seed. They are not real news.

## Offline (no key)

```
python sidecar/score_posts.py --scorer mock --out data/text_signals_mock.jsonl
```

The mock is a deterministic keyword scorer labelled `mock-keyword-v1` in every
line it writes. It needs no packages beyond the standard library.

## With Jev

Use a virtual environment (the global Python on the build machine hit a TLS
`RecursionError` inside `truststore` with `typesafe-sdk`; a clean venv does not):

```
python -m venv .venv
.venv/Scripts/pip install -r sidecar/requirements.txt      # Windows; .venv/bin/pip elsewhere
export TYPESAFE_API_KEY=...                                  # in your shell only
.venv/Scripts/python sidecar/score_posts.py --stats sidecar/scoring_stats_jev.json
```

The SDK reads `TYPESAFE_API_KEY` from the environment. The script never reads,
prints or writes the key. With no key set, `--scorer auto` (the default) falls
back to the mock.

One Jev `system_one` call per post asks five questions at once: is it about
BTC (`Noul`), is it about ETH (`Noul`), the implied direction for each
(`Choice` of bullish / bearish / neither), and whether it is new information
(`Noul`). `ts` in the output is publication time plus the measured scoring
latency, so a backtest never sees a score before it existed.

## Files

| file | what |
|---|---|
| `make_posts.py` | writes `posts_sample.jsonl` (synthetic) |
| `score_posts.py` | scores posts with Jev or the mock |
| `posts_sample.jsonl` | 60 synthetic posts |
| `scoring_stats_jev.json` | latency and token counts from the real Jev run |
| `scoring_stats_mock.json` | the mock's summary |
| `../data/text_signals.jsonl` | Jev-scored features (used by `backtest` by default) |
| `../data/text_signals_mock.jsonl` | mock-scored features |
